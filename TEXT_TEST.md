# Тестовые примеры

В пояснительной записке разбор результатов работы синтаксического анализатора иллюстрируется **рисунками 4–7** (несколько сценариев запуска).

## Что проверять в приложении

1. **Корректное объявление** — одна строка вида  
   `const name: string = 'text';`  
   Ожидается отсутствие синтаксических ошибок в панели парсера.

2. **Пустая строка** —  
   `const empty: string = '';`

3. **Ошибки в идентификаторе, типе, знаках `:` `=`**, несоответствие шаблону — должны фиксироваться сообщениями парсера с указанием фрагмента и позиции.

4. **Несколько строк подряд** — парсер обрабатывает последовательность объявлений (построчно), накапливая список ошибок при необходимости.

Практические ожидаемые формулировки ошибок и граничные случаи дополнительно закреплены в автотестах синтаксиса проекта (`tests/examples_syntax.cpp`) и в документации к парсеру в каталоге `docs/`.
