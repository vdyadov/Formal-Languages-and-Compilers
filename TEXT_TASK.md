# Постановка задачи

**Тема курсовой работы:** объявление и инициализация строковой константы на языке Pascal.

**Цель:** выполнить программную реализацию алгоритма синтаксического анализа объявлений и инициализаций строковых констант на языке Pascal.

## Сущность объекта разбора

Строковые константы — это фиксированные последовательности символов, значение которых не меняется в процессе выполнения программы. В рамках данного проекта литерал строки задаётся в **одинарных кавычках** (как принято в классическом Pascal).

Для описания строковых констант в языке Pascal используется служебное слово `const`.

## Формат записи

```text
const имя: string = 'строка';
```

## Примеры

- Простое объявление: `const val: string = 'value';`
- Пустая строка: `const empty: string = '';`

## Допустимые конструкции (в терминах разработанного парсера)

Синтаксический анализатор объявлений строковых констант считает корректными, в частности, такие записи:

```pascal
const VERSION1: string = '1.0.2';
const PRIVATE: string = 'top secret';
const empty: string = '';
const NAME: string = 'value';
```
