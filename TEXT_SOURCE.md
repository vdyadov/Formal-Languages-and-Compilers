# Исходный код программы

Полный листинг программной части синтаксического анализатора объявлений и инициализации строковых констант содержится в **исходных файлах репозитория** (аналог приложения к пояснительной записке).

## Язык и платформа

- **Язык:** C++ (стандарт C++17).
- **Интерфейс:** Qt 6 (виджеты).
- **Проект:** `Compiler.pro` (Qt Creator / qmake).

В пояснительной записке в приложении Б могут встречаться устаревшие формулировки про другой язык реализации; актуальная реализация курсового приложения — **C++/Qt**, как указано в **«О программе»**.

## Основные модули

| Файл | Назначение |
| ---- | ---------- |
| `lexer.cpp`, `lexer.h` | Лексический анализ входного текста |
| `parser.cpp`, `parser.h` | Синтаксический разбор объявлений `const … string = '…';` |
| `token.h` | Описание лексем и вспомогательных структур |
| `mainwindow.cpp`, `mainwindow.h`, `mainwindow.ui` | Главное окно, меню, запуск анализа |
| `codeeditor.cpp`, `codeeditor.h` | Редактор кода |
| `infowindow.cpp`, `infowindow.h` | Окна со справкой и текстовыми разделами (Markdown) |

## Как просмотреть код

Откройте перечисленные файлы в Qt Creator или другом редакторе из корня проекта. Для автоматической проверки поведения парсера используется цель сборки тестов в каталоге `tests/`.
