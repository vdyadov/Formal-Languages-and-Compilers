# Классификация грамматики

Согласно **иерархии Хомского**, грамматика **G[‹START›]**, описывающая объявление строковой константы в выбранном виде, относится к классу **автоматных (тип 3)** грамматик.

## Праворекурсивный вид

Правила грамматики можно представить в виде **праворекурсивных** продукций вида **A → aB | a | ε**, где:

- **A**, **B** — нетерминалы;
- **a** — цепочка терминалов (в частности, один терминал).

Для **G[‹START›]** цепочка продукций, приведённая в разделе «Грамматика», согласуется с этим ограничением: на каждом шаге к текущему нетерминалу «пристраивается» префикс из терминалов, а далее разбор продолжается по следующему нетерминалу.

## Вывод

Автоматность грамматики позволяет реализовать разбор как **распознавание цепочки конечным автоматом** (в программе — детерминированная последовательность состояний парсера по потоку лексем).
