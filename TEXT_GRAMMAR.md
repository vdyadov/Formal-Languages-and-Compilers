# Разработка грамматики

Ниже приведён **граф конечного автомата лексического анализатора**: классификация входных символов в коды лексем (ключевое слово `const`, тип `string`, идентификатор, пробел, операторы `:` и `=`, строковый литерал, `;`, ошибка).

![Граф конечного автомата лексера](qrc:/TEXT_GRAMMAR_fsm.png)

Определим грамматику объявлений строковых констант языка Pascal **G[‹START›]** в нотации Хомского с множеством продукций **P**.

Ниже приведена цепочка правил, отражающая структуру конструкции `const … : string = '…';` (нетерминалы условно названы по роли фрагмента входной цепочки).

```text
<START>      -> 'const' <SPACE>
<SPACE>      -> '_' <ID>
<ID>        -> идентификатор <COLON>
<COLON>     -> ':' <TYPE>
<TYPE>      -> 'string' <EQUALS>
<EQUALS>    -> '=' <APOSTROPHE>
<APOSTROPHE> -> ' <SYMBOL>
<SYMBOL>    -> symbols <APOSTROPHE>
<APOSTROPHE> -> ' <SEMICOLON>
<SEMICOLON> -> ';'
```

Здесь **`symbols`** — последовательность символов тела строки; **одинарные кавычки** ограничивают литерал слева и справа. Правило для `<SPACE>` в записке моделирует пробел после `const` перед именем; в реализации лексера допускается типичная разметка с пробелами вокруг знаков.

## Составляющие грамматики

- **Z** = ‹START› — аксиома.
- **Vt** — терминальный алфавит: ключевое слово `const`, знаки `:`, `=`, `;`, одинарные кавычки, пробельные символы, буквы и цифры в идентификаторе и т.д.
- **Vn** — нетерминалы: ‹START›, ‹SPACE›, ‹ID›, ‹COLON›, ‹TYPE›, ‹EQUALS›, фазы разбора литерала и ‹SEMICOLON›.

Конкретная реализация в программе задаётся лексером (выделение лексем) и парсером (последовательная проверка шаблона объявления).
